Free static / web hosting (catalog & agent-friendly)

agent-OK = CLI / API / git deploy that AI agents can drive · manual = mainly drag-drop or human UI

ServiceURLDescriptionAgent
GitHub Pages pages.github.com Free static hosting from a public repo (*.github.io). This hub + catalog live here. agent-OK
Netlify netlify.com · Drop Drag-file Drop for instant *.netlify.app; also git + Netlify CLI for CI deploys. Excellent for static SPAs. agent-OK Drop=manual
Cloudflare Pages pages.cloudflare.com Git-connected or Wrangler CLI deploy; global CDN; free tier generous for static sites (*.pages.dev). agent-OK
Vercel vercel.com Git + Vercel CLI; top-tier static / Next.js hosting; free hobby tier. agent-OK
Firebase Hosting firebase.google.com/docs/hosting Google account; firebase deploy CLI; good when you may add Functions / backend later. agent-OK
Surge.sh surge.sh Ultra-light CLI (surge ./dist); single-command static publish; free custom subdomain. agent-OK
Tiiny.host tiiny.host Upload a zip / HTML for a tiny public URL; great for one-off demos; limited free plan. manual
Google Sites sites.google.com Easiest share for docs/intranet pages; not suited to full custom HTML / thumbnail catalogs. manual
Render (Static Sites) render.com/docs/static-sites Free static sites from git; auto TLS; simple env for agents with Render API/CLI. agent-OK
GitLab Pages docs.gitlab.com/…/pages CI-driven static publish from GitLab repos; similar model to GitHub Pages. agent-OK
Codeberg Pages docs.codeberg.org/codeberg-pages Free Pages on Codeberg (Forgejo); good FOSS alternative when GitHub is blocked. agent-OK
Neocities neocities.org Classic personal-site host; API + CLI for uploads; free tier with size limits. agent-OK
Deno Deploy deno.com/deploy Edge deploy via deployctl / git; free tier for static + Deno apps. agent-OK
Azure Static Web Apps learn.microsoft.com/…/static-web-apps Free tier; GitHub Actions / SWA CLI; optional API functions on Azure. agent-OK
Cloudflare Workers + Assets developers.cloudflare.com/…/static-assets Wrangler-driven static assets on Workers; pairs with Pages for more control. agent-OK
Railway (static / Nixpacks) railway.app Git + Railway CLI; free trial credits — check current free limits before agent loops. agent-OK
Fly.io fly.io flyctl deploy; free allowance for small apps; overkill for pure static but agent-friendly. agent-OK
Koyeb koyeb.com Git / CLI deploy; free instance tier useful for tiny static or edge services. agent-OK

For A.I.R.I.S. catalog / hub static HTML: prefer GitHub Pages (current), then Netlify / Cloudflare Pages / Vercel / Surge when you need a second origin or agent CLI deploy outside GitHub.
